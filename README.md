# Onyx Launcher website

[![Onyx Launcher — open-source Minecraft launcher for Windows and Linux](https://lonestill.github.io/social-card.png)](https://lonestill.github.io)

This repository contains the official website for
[Onyx Launcher](https://github.com/lonestill/onyx-launcher), an open-source
Minecraft launcher for Windows and Linux.

The site presents the launcher's main features, English interface screenshots,
verified release downloads, and installation options. Production is published
at [lonestill.github.io](https://lonestill.github.io).

## Local development

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Deployment

Pushes to `main` are built and deployed automatically with GitHub Actions and
GitHub Pages.

Launcher documentation, issues, and releases live in the
[main Onyx Launcher repository](https://github.com/lonestill/onyx-launcher).
